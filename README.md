## Индивидуальный вариант

Номер в журнале N = 20, вариант считается по формуле `((N - 1) % 8) + 1 = 4`.

| Работа | Что задаёт вариант 4 |
|---|---|
| ПР1 | `totalTasks = 20`, `completedTasks = 11`, `dailyLimit = 6` |
| ПР2, ПР3, ПР4 | набор `variantTasks` из шести задач, тема «Подготовка семинара» |
| ПР5 | фильтр `{ priority: "medium" }`, ожидаемые id `[1, 10, 19, 28]` |
| ПР6 | начальный фильтр `priority=medium`, создание задачи среднего приоритета |

Общие контрольные наборы (`demoTasks`) при этом не заменяются: проверки выполняются
и на них тоже.

## Запуск

```bash
# ПР1 (Node.js)
node practice-01/js/progress.js

# ПР2: демонстрационный сценарий и проверки
node practice-02/src/main.js
node practice-02/checks.js

# ПР3: локальный сервер (http://127.0.0.1:5503/)
cd practice-03 && npm start

# ПР4: проверки и локальный сервер (http://127.0.0.1:5504/)
cd practice-04 && npm test && npm start

# ПР5: проверки, затем API (http://127.0.0.1:5505/api) и клиент во втором терминале
cd practice-05 && npm test
cd practice-05 && npm start
cd practice-05 && npm run client

# ПР6: проверки, затем API и приложение (http://127.0.0.1:5506/)
cd practice-06 && npm test && npm start
```

Для ПР3, ПР4 и ПР6 модули подключаются через `type="module"`, поэтому страница
открывается через локальный сервер, а не двойным щелчком по `index.html`.
